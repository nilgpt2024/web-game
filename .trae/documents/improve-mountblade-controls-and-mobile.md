# 改进「骑马与砍杀」操控与移动端适配方案

## Context

当前游戏（`games/Action/Archery-3D`）已完成功能改造，但玩家反馈存在三个核心体验问题：

1. **操控手感差**：马匹转向速率与速度无关，高速冲刺时仍能原地快速自转，加减速曲线过于线性，导致“飘”。
2. **马头朝向难辨**：马匹模型由同色系方块组成（头、颈、身均为棕色），缺乏明显正反面标识，远距离难以判断朝向。
3. **无移动端适配**：当前仅支持桌面键盘鼠标（WASD + 鼠标锁定瞄准），没有虚拟摇杆、触屏瞄准或触控按钮。

本方案通过视觉增强、输入抽象重构与移动端触控层，解决上述问题。

## Implementation Plan

### 1. 视觉：明确马头方向

修改 `src/units.ts` 的 `createHorseMesh`：

- **前脸分色**：将马头拆分为“前额/鼻口”与“后脑勺”两部分，前额使用浅米色/灰色材质，与身体形成对比。
- **添加马耳**：在头顶前侧添加两个小型圆锥，微微前倾，强化“前方”几何特征。
- **添加鬃毛**：沿马颈到背部添加一排深色窄长方体，形成从头部向后的视觉流线。
- **鞍褥（caparison）**：将扁平鞍座改为覆盖马背的彩色布垫，前窄后宽、两侧下垂；使用阵营色（玩家/友军蓝色，敌军红色），玩家马匹前缘加黄色滚边。
- **玩家专属标记**：在 `createPlayer` 中给玩家马匹添加额前黄色冠羽或亮色护甲片，避免与友军骑兵混淆。

### 2. 操控手感优化

修改 `src/config.ts` 与 `src/player.ts`：

- **输入抽象**：将 `PlayerController.input` 从布尔按键改为模拟量：
  - `move: number`（-1..1，对应前后）
  - `turn: number`（-1..1，对应左右）
  - `sprint: boolean`
  - `attack: boolean`
- **速度相关转向**：高速时降低转向灵敏度，低速时更灵活；冲刺时进一步惩罚转向。
- **平滑转向**：对转向输入做插值平滑，避免突变。
- **更自然的加减速**：
  - 降低倒车最大速度，减少误操作。
  - 提高刹车减速度，让马匹更有“重量感”。
- **镜头倾斜**：转向时给相机加入轻微侧倾（bank），增强速度感。
- **相机惯性**：适当降低相机跟随 lerp 系数，减少生硬感。

### 3. 移动端触控操作

新增触控 UI 与输入处理：

- **屏幕分区**：
  - 左半屏：虚拟摇杆（移动 + 转向）。
  - 右半屏：视角/瞄准区，单指拖动调整 `cameraYaw` 与 `cameraPitch`。
  - 右下角：操作按钮组（攻击/拉弓、冲刺、切换武器）。
- **虚拟摇杆**：
  - 左下角固定外圈，按下时显示并吸附到触点。
  - 水平分量控制转向，垂直分量控制前后移动。
  - 设置 15% 死区，避免误触。
- **攻击按钮**：
  - 弓模式：按住蓄力、松开发射，与桌面鼠标共用同一拉弓逻辑。
  - 剑模式：点击挥砍。
- **武器切换按钮**：点击在弓/剑间切换，同步更新 HUD。
- **Pointer Lock 适配**：移动端点击“开始”时不再请求 `requestPointerLock`，仅桌面模式请求。

### 4. 文件改动

| 文件 | 改动内容 |
|------|----------|
| `src/config.ts` | 新增/调整转向、速度、触控灵敏度常量 |
| `src/player.ts` | 重构输入抽象、更新 `updatePlayer` 与 `updatePlayerCamera`、桌面输入绑定 |
| `src/units.ts` | 增强马匹模型（前脸、马耳、鬃毛、鞍褥、阵营色） |
| `src/main.ts` | 添加触控事件监听、移动端开始流程适配、输入状态与拉弓逻辑共用 |
| `index.html` | 新增触摸控件容器（摇杆、视角区、按钮） |
| `src/style.css` | 添加触控控件样式，确保按钮可点击区域足够大 |

## Verification

1. **桌面回归**：WASD、鼠标瞄准、左键拉弓/挥剑、`1/2` 切武器、`Shift` 冲刺均正常；高速冲刺时不能原地快速自转。
2. **视觉检查**：玩家马匹头部有明显前脸分色、马耳、鬃毛、鞍褥和额前冠羽；友军蓝色鞍褥，敌军红色鞍褥。
3. **移动端模拟**：Chrome DevTools 切到移动设备，确认触摸控件出现；左摇杆控制移动转向，右屏拖动瞄准，按钮可蓄力射击、挥砍、切换武器。
4. **边界场景**：双手同时触摸不冲突；游戏结束弹窗可正常点击重新开始；切换标签页后输入状态不 stuck。
