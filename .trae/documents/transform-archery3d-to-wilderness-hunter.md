# Plan: 将 Archery-3D 改造为 Wilderness Hunter（荒野猎人）

## Context
当前 `games/Action/Archery-3D/` 是一个静态靶场 3D 射箭游戏。用户希望将其改造为一款“荒野猎人”生存狩猎模拟游戏：保留拉弓射箭核心玩法，但把固定靶子替换为多种会移动/受惊的生态猎物，增加风向气味、有限箭矢、倒计时等生存机制，并整体换成荒野森林主题。

## Requirements
- 游戏类型：生存狩猎模拟。
- 猎物：5 种生态动物（兔、狐、鹿、野猪、熊），不同速度、体型、分值、行为与生命值。
- 动物行为：Idle / Patrol / Alert / Flee / Dead 状态机；闻到玩家气味或箭矢近失会警觉逃窜。
- 风向/气味：顺风方向猎物更早发现玩家；同一风向同时影响箭矢弹道偏移。
- 生存机制：每轮 10 支箭、120 秒倒计时、14 只猎物；时间到或箭尽结束。
- 计分：基础分 × 命中部位倍率 × 距离加成；头部高倍率，腿部可减速但未击杀分值低。
- 美术：仅使用 Three.js 基础几何体（无外部图片/模型），低多边形风格。
- 集成：GameHub 大厅展示名改为“Wilderness Hunter / 荒野猎人”，更新相关 i18n。

## Proposed Changes

### 1. 代码模块拆分（`games/Action/Archery-3D/src/`）
从单文件 `main.ts` 拆分为：
- `config.ts`：游戏常量、猎物配置表 `ANIMAL_TYPES`、击中部位配置。
- `environment.ts`：起伏地形、密集森林（InstancedMesh）、狩猎台、岩石/灌木。
- `animal.ts`：`Animal` 类、状态机、程序化动物几何体生成、受击/死亡处理。
- `main.ts`：场景初始化、输入处理、箭矢物理、游戏循环、HUD 与消息更新。
- `style.css`：适配新 HUD（得分、命中率、风向、箭矢、时间、猎物数量）。

### 2. 猎物配置（`config.ts`）
| 动物 | 基础分 | 行走/奔跑速度 | 警觉范围 | 行为 | 生命值 |
|---|---|---|---|---|---|
| 兔 | 150 | 1.4 / 9.0 | 18 | 胆小 | 30 |
| 狐 | 300 | 1.2 / 7.0 | 28 | 谨慎 | 60 |
| 鹿 | 500 | 1.0 / 6.0 | 35 | 谨慎 | 100 |
| 野猪 | 650 | 0.9 / 5.5 | 30 | 凶猛 | 140 |
| 熊 | 1000 | 0.6 / 4.5 | 45 | 凶猛 | 240 |

命中部位：head ×2.5、body ×1.0、leg ×0.5（腿部命中降低猎物速度 30%）。

### 3. 环境与场景
- 地形：使用正弦叠加生成轻微起伏地面，动物与地面实时贴合。
- 森林：90 棵低多边形树分簇分布，树木/灌木/岩石使用 `InstancedMesh`。
- 狩猎台：离地约 3.2 m 的木台，带支柱与护栏；玩家固定在此射击。
- 天空/光照：调整为黄昏/森林氛围色调。

### 4. 动物 AI 状态机
- `idle`：站立摆头，定时转 patrol。
- `patrol`：慢走觅食，定时转 idle。
- `alert`：停止并注视威胁方向，0.8–1.5 秒后确认威胁转 flee。
- `flee`：逃离威胁位置 3–5 秒，再转 patrol。
- `dead`：倒地、淡出、移除。

特殊行为：兔/狐逃跑带 Z 字形抖动；野猪/熊未死时可能短距离冲向箭来方向再 flee。

### 5. 风/气味与箭矢物理
- `wind` 使用 `THREE.Vector2`，每 20–30 秒平滑过渡一次。
- 气味检测：计算玩家到猎物的方向与风向点积，顺风方向有效警觉范围扩大。
- 箭矢风偏：`velocity.x += wind.x * dt * 0.35; velocity.z += wind.y * dt * 0.35`。
- HUD 风向箭头实时旋转。

### 6. 游戏循环与计分
- 开始：重置状态、随机风向、生成 14 只猎物（按权重：兔 35%、狐 25%、鹿 20%、野猪 12%、熊 8%）。
- 每帧：更新计时器、风向、箭矢物理、动物 AI、碰撞检测、HUD。
- 命中判定：先球体快速剔除，再细化检测命中部位。
- 结束条件：时间到 0 或箭矢耗尽。结束画面显示最终得分、击杀数、命中率等。

### 7. UI/HUD 调整（`index.html` + `style.css`）
显示项改为：得分、命中率、风向（箭头）、箭矢剩余、倒计时、剩余猎物。
覆盖层文案改为狩猎主题，移除“清除箭矢”按钮，保留“开始/重新开始”。

### 8. 国际化更新
- `game-i18n.js`：删除 `specific['Archery-3D']`，新增 `specific.WildernessHunter`（中英双语），包含动物名称、命中反馈、结束文案。
- `i18n.js`：新增大厅级翻译 `Wilderness Hunter` / `Wilderness Hunter_desc`。

### 9. GameHub 大厅注册
- `script.js` Action 数组中将 `Archery 3D` 替换为：
  ```js
  { name: 'Wilderness Hunter', path: 'games/Action/Archery-3D/dist/index.html', icon: 'fas fa-bullseye', desc: '荒野生存狩猎' }
  ```
- 根 `index.html` 游戏总数 55 与 Action 数量 16 保持不变。

### 10. 构建产物
- `package.json` 中 `name` 改为 `wilderness-hunter`。
- 改造完成后执行 `npm run build` 重新生成 `dist/`。

## Verification Steps
1. 在 `games/Action/Archery-3D/` 运行 `npm run build` 成功。
2. `npm run preview` 访问 `http://127.0.0.1:4191/`：
   - 覆盖层显示“荒野猎人”与狩猎规则；
   - 开始游戏后 HUD 显示箭矢/时间/风向/猎物；
   - 猎物在森林中 Idle/Patrol；
   - 射失后附近猎物警觉并逃跑；
   - 命中不同部位得分正确，头部通常直接击杀；
   - 时间到或箭尽弹出结束画面。
3. 从 GameHub 大厅点击卡片进入游戏，路径与返回大厅正常。
4. 中英文切换，确认所有新文案生效。

## Assumptions & Decisions
- 目录名保留 `Archery-3D`，仅改展示名，避免改动大厅路径与历史链接。
- 不使用外部资源，确保离线部署和无版权问题。
- 不引入复杂骨骼动画，死亡/移动使用简单几何变换与淡出。
- 玩家位置固定在狩猎台，相机仅随瞄准轻微偏转，保持实现可控。
