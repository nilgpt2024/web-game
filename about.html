What is AIGameHub

AIGameHub is a curated collection of 500+ free AI-generated browser games. Every entry on this site was built with a generative model somewhere in the pipeline — a model that wrote the first playable version, generated the art, produced the level layouts, or acted as the opponent. We find these games in the open-source community, verify that each one actually runs, and present them in a single place where you can open and play them instantly in your browser.

You do not need an account, a download, or a powerful computer. Every game here is pure HTML5: it loads in seconds, runs on desktop and mobile alike, and works on a phone as easily as on a laptop. If you are new to AI-generated games, the free AI games online collection is the fastest way to see what the category looks like today, and best AI browser games gathers the entries we consider the strongest of the bunch.

Vision & Mission

Vision

To be the largest curated hub of open-source AI-generated games, so that anyone can experience what AI-assisted game creation produces — zero cost, zero friction.

Mission

To keep finding, verifying, and organizing AI-generated open-source games so that great projects scattered across GitHub are easy to discover and play, and to give their creators the credit they deserve.

What Makes It Different

Plenty of sites aggregate "AI games". This hub is built around three commitments that we think matter more than raw numbers:

Genuinely AI-Generated

Every listed game was built with a generative model in the loop — not just branded "AI" in its marketing. Our vibe coded games collection shows the clearest examples

Verified Playable

Each entry is tested before it is listed. If a build does not run, it does not make the directory

Explained for Humans

Each game page describes what the game is, how it plays, and what to expect — so you can pick in ten seconds

Honest About Origins

Author credit and license terms stay with every game. Adapted builds are labelled, and takedown requests are honored quickly

Game Categories

The directory currently holds 508 playable games across 7 categories, plus a separate wing of 101 AI-generated interactive art experiences. Counts update as the collection grows:

Arcade (130) Action (123) Casual (117) Puzzle (82) Board (32) Typing (8) Memory (4)

Most entries are short-session games built around one mechanic and a score — ideal for a two-minute break. If you prefer games where the machine itself is the opponent, the AI opponent games collection is the place to start; if you want to see the frontier of what models like GPT-6 Astra produce, browse the GPT-6 Astra games wing. The blog adds longer write-ups on notable entries.

Under the Hood

The entire site is static: no backend, no accounts, no tracking walls between you and the games. That is a deliberate choice — it is what keeps every page loading in under a second and keeps the collection resilient.

HTML5

Semantic markup, Canvas and WebGL for rendering, LocalStorage for progress

CSS3

Custom properties, Grid/Flexbox, animations, dark theme, responsive layout

JavaScript

ES6+, all game logic runs client-side in your browser

Cloudflare

Pages hosting, global CDN, automatic deploys on every commit

Open Source & Licensing

AIGameHub does not develop — or own the copyright to — the games it lists. Every game was created by its original author or team and published under an open license such as MIT, Apache-2.0, GPL, or CC0. We aggregate, organize, and explain; the credit stays where it belongs.

Our Open-Source Commitments

  • Copyright for each game remains with its original author; we only aggregate and present
  • Author attribution and license information are kept with each game page and in the source repository
  • If an original author does not want their game listed, email 2952671670@qq.com or open a GitHub issue and we will remove it after verification
  • The hub's own aggregation code (not the games themselves) is open source on GitHub — fork it and build your own collection
