开源理念

AIGameHub 是一个完全开源的项目，我们相信开源的力量。

开源承诺

  • 网站源码完全开源，欢迎学习和修改
  • 游戏来自开源社区，遵循各自许可证
  • 欢迎提交 Issue 和 Pull Request 参与贡献
  • 持续收录更多优质开源 AI 游戏

游戏来源与开源许可证

AIGameHub 本身不开发、也不拥有站内游戏的版权。站内游戏均采集自 GitHub 等公开开源社区，由各自的原作者或团队创作，并以 MIT、Apache-2.0、GPL、CC0 等开源/开放许可证发布。我们尊重每一位原作者的劳动成果：

  • 每款游戏的版权归原作者所有，平台仅作聚合、整理与中文化展示
  • 游戏页面与仓库中保留原作者署名与开源许可证信息；如原项目要求注明来源，我们会在对应位置标注
  • 若某款游戏的原作者不希望被收录，或认为收录存在许可问题，可通过邮件 2952671670@qq.com 或 GitHub Issues 联系我们，我们将在核实后及时下架
  • 本站自身的聚合页面代码（不含游戏本体）以开源方式发布于 GitHub 仓库
