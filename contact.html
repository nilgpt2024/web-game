常见问题

AIGameHub 收费吗？

完全免费！所有游戏均可免费游玩，无内购、无广告、无需注册。网站靠开源社区和个人兴趣维护。

如何贡献游戏？

欢迎贡献！步骤：Fork 仓库 → 添加游戏文件 → 更新 gamesData → 提交 Pull Request。请确保游戏是开源的且遵循对应许可证。

游戏存档会丢失吗？

游戏进度存储在您浏览器的 localStorage 中。清除浏览器数据、更换设备或使用无痕模式都会导致存档丢失。我们无法恢复存档。

支持哪些浏览器？

支持所有现代浏览器：Chrome、Firefox、Safari、Edge。建议使用最新版本以获得最佳体验。部分游戏需要 Canvas 和 Web Audio API 支持。

可以商用吗？

网站源码采用 MIT 许可证，可自由使用和修改。但各游戏有各自的开源许可证，商用前请仔细阅读对应游戏的 LICENSE 文件。

如何举报侵权内容？

如您认为网站上的内容侵犯了您的权益，请通过邮件发送 DMCA 通知，包含版权证明和具体 URL，我们会尽快处理。
