# Diablo-JS 战斗大改设计文档

日期：2026-09-29
状态：已确认（用户选择：战斗体验为重心 / 怒气系统 / AI 中等改造 / 一次到位）

## 目标

把战斗从「站桩互殴、技能好了就按」升级为「有资源管理、有操作反馈、有走位对抗」的战斗循环。全程保持单文件纯前端 ES5，不改部署方式。

## 现状问题（审计结论）

1. 无伤害数字/特效/震屏，打击感为零
2. 三武器仅数值不同（180/340/140），无攻速/范围/射程差异，火法杖伤害反而最低
3. 技能纯冷却制，无资源管理
4. AI 每 200ms 随机走+直线追击，远程怪站桩对射，近战怪扎堆，BOSS 技能无预警
5. 怪物被击无硬直，近战无压制感

## 设计

### 1. 怒气系统（Commit 1）

- HUD 血条下方新增红色怒气条，0–100，初始 0
- 获得：近战命中 +12（长剑 +50% 即 +18）、被击中 +6、冲锋命中 +8
- 消耗：火球术 35、战吼 40、冲锋免费
- 衰减：脱战 3 秒后每秒 -8
- 冷却仅防连点：火球 0.5s、战吼 8s、冲锋维持现有
- 火球伤害改为跟随武器伤害（法杖 ×2.2），废除固定 220
- 数值入口：`RAGE` 常量对象集中管理

### 2. 武器差异化（Commit 2）

- 新增 `WEAPONS` 配置表替代散落硬编码：

| 武器 | 伤害 | 攻击间隔 | 特性 |
|------|------|----------|------|
| Blade | 180 | 0.35s | 均衡，怒气获取 +50% |
| War Axe | 340 | 0.70s | 横扫：主目标全额 + 扇形范围其他敌人 60% |
| Fire Staff | 140 | 0.50s | 远程火弹射程 300；火球术 ×2.2 |

- 攻击间隔按武器表执行（现为统一硬编码）
- 横扫判定：以目标方向为轴的扇形（半径 90px、±60°），其余命中敌人吃 60%

### 3. 打击感套餐（Commit 3）

- 伤害数字：Canvas 浮动文字，上浮渐隐 0.7s；白=英雄对怪，红=怪对英雄
- 受击闪白：怪物被命中当帧叠加白色
- 火花粒子：每次命中 4–6 个沿攻击方向飞溅；全屏粒子 ≤40（保手机性能）
- 击退：近战命中推开 10px，推前用 isWayWall 检查防穿墙
- 屏幕震动：英雄被击中/BOSS 重击震 4–6px、0.15s
- 实现入口：新增 `Fx` 粒子/文字管理器与渲染钩子

### 4. AI 中等改造（Commit 4）

- 远程怪（FS/SI）风筝：与英雄保持 180–260 距离带，太近后退、太远逼近，进入距离带才射击
- 近战怪防扎堆：与其他怪距离 <40px 时侧向分离
- 受击硬直：怪物被击中后 0.25s 不移动不攻击
- BOSS 技能（旋风/召唤/火雨）统一加 0.8s 红色半透明预警圈，圈显示期间不落伤害，结束后结算
- 沿用已修复的 nextStep 滑动移动，不再重复修

## 非目标（YAGNI）

- 不做暴击/护甲/抗性数值体系
- 不做状态机 AI / 精英怪变体
- 不做小地图与交互入口重构（另开需求）
- 不做存档

## 风险与对策

- 怒气衰减令玩家困惑 → 怒气条在脱战衰减时轻微脉动提示
- 击退穿墙 → isWayWall 预检
- 手机性能 → 粒子上限 40，伤害数字上限 20
- 一次到位改动面大 → 每节独立 commit（版本号 v=20260929w 起递增），可逐步回滚

## 边界规则（审查补充）

1. **英雄攻击间隔**：点击攻击受 `WEAPONS[cur].interval` 限制；间隔未到时点击视为纯移动指令（不排队、不缓存攻击）。怪物攻击节奏维持现有 setInterval 结构不变。
2. **扇形/距离判定坐标系**：全部在屏幕坐标系完成（与现有索敌一致，怪物相对英雄的屏幕位移向量点积求夹角）；横扫只对怪物结算、不与墙交互，无需碰撞校验。
3. **BOSS 预警圈结算**：技能改为两段——施法段 0.8s（显示圈，BOSS 停止移动与普攻）→ 结算帧一次性判定（圈内英雄受伤 / 召唤 / 火雨落点伤害），圈期间无持续伤害。
4. **性能边界实现**：粒子数组硬上限 40（超限挤掉最老）、伤害数字上限 20；均为每帧遍历的普通数组，无额外对象分配热点；怒气条在 `renderHeroHealth()` 之后单次追加绘制，不新增每帧循环。
