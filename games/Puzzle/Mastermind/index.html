Mastermind Game Introduction

Mastermind is the classic code-breaking game: one side sets a secret color sequence, the other guesses within a limited number of tries. Each guess earns feedback — black pegs for correct color and position, white pegs for correct color in the wrong spot.

Use each round's feedback to eliminate and adjust until you deduce the exact code. Excellent training in inductive reasoning and logical elimination.

How to Play Mastermind

Fill a row with colors and submit; then adjust using the pegs — black for right color and spot, white for right color wrong spot, none for colors not in the code. Crack it within the limit to win.

Controls

  • Click colors to fill the guess row
  • Submit and read the peg feedback
  • Black: correct color and position
  • White: correct color, wrong position

Features

  • Classic code-breaking with narrowing clues
  • Trains induction, elimination and logic
  • Adjustable colors and code length
  • Runs fully offline — no sign-up

Tips & Tricks

  1. Open with repeated or similar colors to learn which are in the code.
  2. Fix confirmed positions and adjust the rest one by one.
  3. A white peg means the color exists — try it in other spots.
  4. Cross out impossible arrangements from earlier rounds to narrow the search.
